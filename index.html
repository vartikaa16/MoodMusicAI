ABOUT THE PROJECT

🤖 About MoodTune

MoodTune is a mood-based music recommendation system created as a Class 12 project.

The user first selects a mood and then chooses between Hindi and English music.

The system displays songs according to both selections.

Features

  • Mood-based recommendations
  • Hindi and English music
  • Song and artist search
  • Favorites
  • Custom playlists
  • YouTube playback
