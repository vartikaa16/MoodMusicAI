About MoodTune

MoodTune is a mood-based music recommendation website. Users can choose their current mood and receive songs that match it.

The website also allows users to search for songs, save favorites and create personalized playlists.

This project demonstrates the use of HTML, CSS and JavaScript to create an interactive web application.
